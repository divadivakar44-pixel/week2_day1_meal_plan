# Week 2 - Day 1: 7-Day Meal Plan Prompt

## Objective
Created a reusable AI prompt to generate a healthy 7-day South Indian vegetarian meal plan for gradual weight loss.

## Features
- Defined an AI meal-planning assistant role.
- Added editable personal details.
- Included vegetarian and South Indian food constraints.
- Generated breakfast, lunch, evening snacks and dinner for seven days.
- Specified portion sizes in a structured Markdown table.
- Added grocery lists and meal preparation tips.
- Included dietary guardrails and allergy considerations.

## Testing
- First run: Tested with moderate activity level and no allergies.
- Second run: Tested with light activity level and peanut allergy.

## Improvements After First Run
1. Added clearer portion-size requirements and locally available ingredients.
2. Improved protein variety and reduced repetitive dishes.
3. Added cooking-time and allergy restrictions to make the prompt reusable.
